# projekt: digitaler kleiderschrank
web-app (html, css, js) for a digital wardrobe that allows users to upload images of their clothing items, categorize them, and create outfits. The app should have a user-friendly interface and support features like filtering by category, color, and season. Users should also be able to save their favorite outfits and share them with friends. läuft im handybrowser und auf dem Desktop. daten nur lokal gespeichert, keine serverseitige datenbank. die app soll offlinefähig sein und die bilder der kleidung lokal im browser speichern. hosting über github pages. die app soll responsive sein und auf verschiedenen geräten gut funktionieren. die benutzeroberfläche soll modern und ansprechend gestaltet sein, mit klaren navigationsoptionen und einer intuitiven bedienung. die app soll auch eine suchfunktion haben, um bestimmte kleidungsstücke schnell zu finden.
